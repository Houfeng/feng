The language

Installation

Begin with one command.

Recommended

Install online

The installer detects your platform, downloads the matching release, and adds Feng to your PATH.

$ curl -fsSL https://feng-lang.com/install.sh | bash
Read the installer before running it ↗

Alternative

Install manually

Download the zip for your platform, extract it, then add the extracted bin/ directory to your PATH.
