Feng 编程语言

清晰，自有章法。

一门为清晰与可靠而设计的静态类型语言。语法简洁，契约显式， 自动管理内存，并可直接与 C 互操作。

安装 Feng

$ curl -fsSL https://feng-lang.com/install.sh | bash

支持 macOS Apple Silicon · Linux x86-64 · Linux ARM64

在 macOS 上编译需要 Xcode 或 Command Line Tools。
