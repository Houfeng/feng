# 官网品牌图标

## 设计与资源

- 官网顶部品牌入口采用已确认的圆角安全留白版本：[黑隼白底水墨 Logo](feng-logo-ink-light-draft-v2.png) 与 [白隼黑底水墨 Logo](feng-logo-ink-dark-draft-v2.png)，保留各自的隼形、飞行姿态与水墨纹理。
- 站内资源分别为 `website/assets/feng-logo-ink-light.png`、`website/assets/feng-logo-ink-dark.png`，从对应原始水墨稿单独等比缩小为 68 × 68 PNG，并进行无损 PNG 压缩；源稿保持不变。每份资源同时覆盖桌面的两倍像素密度与手机的约 2.125 倍像素密度。
- 保持原有响应式外框：桌面为 34 × 34 CSS px、9 px 圆角；视口宽度不超过 560 px 时为 32 × 32 CSS px、8 px 圆角。背景图使用完整显示区域，不增加内边距；原图中的安全留白避免圆角裁切翼尖。
- 沿用原有品牌入口的明暗对比：浅色主题使用黑底白隼，深色主题使用白底黑隼。资源名中的 `light` / `dark` 沿用设计稿的底色命名，因此浅色主题引用 `dark` 资源，深色主题引用 `light` 资源。图标跟随既有主题状态，关闭 JavaScript 时跟随系统偏好；作为装饰背景，由品牌链接已有的无障碍名称说明用途。

## 接入范围

八个语言首页与用户手册共用模板使用同一品牌图标元素，资源、主题、尺寸与圆角规则统一维护在 `website/styles.css`。图片路径相对该样式表解析，兼容首页直接预览与任意深度的手册章节。用户手册 HTML 通过既有构建入口生成，不直接修改生成结果。

网站内容与交互规则见 [官网规范](../docs/engineering/feng-website.md)。验收检查首页和手册在明暗主题、桌面及窄屏下的图标加载、对应响应式尺寸与首页链接。

## 验证记录

- 圆角安全留白版本的 light PNG 为 3540 字节，dark PNG 为 1920 字节，均为 68 × 68。
- 安全留白版接入后，手册构建生成 62 页；中文首页与手册在桌面/手机、light/dark 下的八个组合检查通过，原显示尺寸、主题映射和零内边距保持不变。
- 用户手册构建成功生成 62 页；浏览器检查覆盖八种语言首页、三处手册页面，以及两种视口与主题的 44 个组合，桌面和手机尺寸分别为 34 × 34、32 × 32。
- 首页与手册的四次手动主题切换、八个禁用 JavaScript 的主题与视口组合均通过；明暗预览已检查。
