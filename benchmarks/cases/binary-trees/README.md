# binary-trees

公共评测方法见 [主规范](../../README.md)。任务参考
[Benchmarks Game binary-trees](https://benchmarksgame-team.pages.debian.net/benchmarksgame/description/binarytrees.html)。

输入为唯一命令行参数：最大深度，范围 6～20，根节点深度为 0。
先构造深度为最大深度加一的伸展树，遍历统计节点后丢弃；然后保留一棵最大深度树。
对深度 4、6、8……不超过最大深度的每一项，分别构造、遍历并丢弃
`2^(最大深度-当前深度+4)` 棵完整二叉树。最后遍历长期存活树。
叶节点也必须是真实节点，禁止以公式替代树构建或遍历。

输出为多行整数：第一行是伸展树节点数；中间每行依次为深度、棵数、节点计数和；
最后一行是长期存活树节点数。校验器独立使用 `2^(深度+1)-1` 计算预期值。
各语言正常管理节点生命周期，不加入终结器计数等内部统计，不要求 GC 在某个固定位置回收。

`quick` 为深度 8，`standard` 为深度 16；正确性检查包含深度 6、7、8。
吞吐量单位为任务要求构造的节点/秒；这是工作量指标，不是实测分配次数。
