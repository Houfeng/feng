# text-scan

公共评测方法见 [主规范](../../README.md)。输入为唯一命令行参数：ASCII 日志文件路径。
每条记录为 `级别,五位十进制整数\n`，级别为 I、W、E。程序读取全部文件后逐字节解析，
输出四个整数：总记录数、W 记录数、E 记录数、所有数值之和。空文件输出四个零。
文件读取、解析和输出均在整程序计时内。

生成器从索引 i=0 开始，级别按 I/W/E 循环，数值为 `(i*17+23)%10000`，补足五位。
每条记录恰好 8 字节。错误格式应以非零状态退出。程序必须从文件计算结果，不能根据
生成规则推导输出。整数求和使用至少 64 位，不引入 Map、正则表达式或 JSON 解析。

`quick` 为 10000 条，`standard` 为 32000000 条（256 MB）。正确性检查覆盖空文件、单条记录、
非生成器样例和格式错误。吞吐量单位为输入字节/秒。输入 SHA-256 与预期输出由生成器
写入运行记录，校验不进入被测进程。
