# Feng Conformance Test Suite

Feng 语言一致性测试集，用于验证 Feng 语言的实现是否与标准一致。

## 项目职责

### `fcts_bin`

一致性测试的可执行入口和行为断言项目。测试用例通常写在此项目中，覆盖 Feng 的语言语法、
语义和运行行为，并通过 `feng run` 执行。

### `fcts_lib`

常规跨包测试的基础提供项目。需要验证包边界、公开声明、制品恢复或 consumer 行为时，将提供者
声明放在此项目中，由 `fcts_bin` 引用和断言。

### `fcts_lib_middle`

多层间接依赖的中间提供项目，依赖 `fcts_lib`，由 `fcts_bin` 消费。仅用于验证
`fcts_bin -> fcts_lib_middle -> fcts_lib` 路径中的制品恢复、泛型具化信息和其他编译期元信息
能够逐层正确传递；普通跨包用例不应使用此项目。

### `fcts_lib_peer`

独立同级提供项目，依赖 `fcts_lib`，但不依赖 `fcts_lib_middle`。仅用于验证两个独立上层项目
共同依赖 `fcts_lib` 时，声明身份、fit、witness、投影槽位及其他包级元信息保持隔离；普通跨包
用例不应使用此项目。

## 项目管理约束

- 未经人工 Review 并明确批准，不得新增 FCTS 项目。
- 新用例优先加入 `fcts_bin`；仅需常规跨包提供者时使用 `fcts_lib`。
- 只有用例必须表达多层间接依赖或独立同级依赖时，才分别使用 `fcts_lib_middle` 或
  `fcts_lib_peer`，不得为单个特性随意创建专用项目。
- 测试项目的依赖方向和职责发生变化时，必须先更新本文并经过人工决策。

## 覆盖范围

- 测试用例由 Feng 语言自身编写，通过 `feng run` 执行。
- 泛型一致性测试应覆盖泛型函数、泛型类型、泛型方法、泛型约束、泛型 spec、泛型 fit、
  泛型 union、泛型数组创建、嵌套泛型默认初始化、泛型对象初始化、spec 作为泛型实参、
  泛型聚合返回、父级约束转发、具体化父泛型 spec，以及跨包泛型使用。
