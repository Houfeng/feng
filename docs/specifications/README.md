# Feng 语言与工具规范

本目录保存 Feng 的权威规范，定义语法、语义、可观察运行时行为、标准库行为、命令行接口、构建与包协议等稳定规则。

## 内容边界

本目录包含：

- 语言语法与语义规则。
- 类型系统、控制流、异常和生命周期等可观察行为。
- 标准库对外行为。
- CLI、构建、依赖和包格式等工具协议。
- 诊断码及其他需要稳定引用的定义。

本目录不包含实现步骤、源码结构、问题排查过程、临时方案或面向初学者的教学内容。此类内容分别归入 [工程文档](../engineering/README.md)、[使用手册](../manual/README.md) 或 [临时记录](../../notes/README.md)。

## 编写规则

- 每项规则只在一个主规范文件中定义，关联规范通过链接引用，不重复定义。
- 规范描述对外行为和约束，不依赖当前实现细节。
- 草案文件应在文件名或正文中明确状态，不得被误认为已经生效的稳定规则。
- 工程实现与使用手册如有歧义，以对应的有效规范为准。

总览入口见 [Feng 语言核心规范](./feng-language.md)。
