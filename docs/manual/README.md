# Feng 用户手册

本目录按语言保存面向 Feng 开发者的使用手册。手册重点说明如何安装、学习和使用 Feng，不解释编译器内部实现。

## 当前语言

- [English（en）](./en/README.md)
- [简体中文（zh-CN）](./zh-CN/README.md)

## 内容边界

用户手册用于编写：

- 安装、环境配置和快速入门。
- Feng 语言功能的使用说明与完整示例。
- 项目创建、构建、运行、测试、调试和依赖管理。
- 标准库、互操作及常见开发任务的使用说明。
- 推荐的代码风格和实践建议。

用户手册侧重任务、示例和使用方式，不解释编译器内部实现。手册中的导航与延伸阅读只引用 `manual/` 内的内容，确保每种语言的手册可以独立发布。

## 多语言规则

- 每种语言使用独立的语言目录；简体中文使用 `zh-CN/`，英文使用 `en/`。
- 不同语言的对应章节保持相同的相对路径和文件名，便于网站建立语言切换关系。
- 各语言目录的 `README.md` 是该语言的手册首页，负责维护章节导航和推荐阅读顺序。
- 翻译必须以已有手册内容为依据，不得在翻译版本中增加独立的语言规则。
- 尚未翻译的章节不创建空文件，也不由网站静默回退到另一种语言。
