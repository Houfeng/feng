# Feng 语言 enum 规范

本文档说明 Feng 中 `enum` 的语法与语义。当前阶段仅支持简单的 int enum：无关联值、无字段、无方法、无泛型。

## 1 职责

- `enum` 用于声明一组离散的具名整型常量，并形成独立的具名类型。
- `enum` 适合表达有限状态、固定类别或协议常量，不等同于直接使用 `int`。
- `enum` 的详细语义以本文档为准；其他文档仅引用，不重复展开。

## 2 语法

正确语法一，隐式取值：

```feng
enum MyKind {
  Kind1,
  Kind2,
  Kind3
}
```

正确语法二，显式取值：

```feng
enum HttpStatus {
  Ok = 200,
  NotFound = 404
}
```

错语法一，混合取值：

```feng
enum TokenKind {
  Unknown,
  Ident,
  Number = 10,
  String,
  Eof
}
```

错语法二，空枚举：

```feng
enum Empty {}
```

错语法三，重复名称：

```feng
enum Bad {
  Ok,
  Ok
}
```

错语法四，枚举项不是整数字面量：

```feng
enum Bad {
  Ok = 1 + 2
}
```

错语法五，在 `enum` 中声明成员：

```feng
enum Bad {
  A,
  let code: int;
}
```

## 3 语义

- `enum` 声明一个新的具名类型，不与 `int` 互相等同。
- 每个枚举项都拥有一个底层 `int` 值。
- `enum` 在语言层保持独立名义类型；其运行时表示与发码表示固定按 `int` 标量处理，不引入额外 runtime 对象或元数据。
- 若一个 `enum` 不包含显式赋值，则各枚举项按声明顺序从 `0` 开始递增 `1`。
- 若一个 `enum` 包含显式赋值，则其全部枚举项都必须显式赋值。
- 显式赋值只允许使用整数字面量，且该值直接成为对应枚举项的底层值。
- 无初始值的 `enum` 绑定，其默认值为该 `enum` 的第一个枚举项。
- 枚举值必须使用 `枚举类型.枚举项` 形式引用。
- 允许从 `enum` 显式转换到 `int`。
- 不允许从 `int` 显式转换到 `enum`，包括整数字面量、常量表达式与一般运行时 `int` 值的 cast；也不允许 `enum` 与 `int` 之间的隐式转换。
- 仅允许同一 `enum` 类型之间直接做 `==` / `!=` 比较；若需要数值比较或算术运算，必须先显式转换为 `int`。
- `enum` 在 C ABI 边界上视为与 `int` 相同的 ABI 标量；具体 ABI 资格与传递规则统一遵循 [Feng 语言 ABI 互操作规范](./feng-interop.md)。

## 4 规则

分为「必须、禁止」。

- [必须] `enum` 声明必须位于模块级顶层。
- [必须] `enum` 至少声明一个枚举项。
- [必须] 同一 `enum` 内的枚举项名称必须唯一。
- [必须] 同一 `enum` 内各枚举项的底层 `int` 值必须唯一。
- [必须] 若一个 `enum` 不包含显式赋值，编译器必须按声明顺序为各枚举项分配从 `0` 开始递增 `1` 的底层值。
- [必须] 若一个 `enum` 包含显式赋值，则其全部枚举项都必须显式赋值。
- [必须] 枚举值引用必须写成 `枚举类型.枚举项`。
- [必须] 无初始值的 `enum` 绑定必须取该 `enum` 的第一个枚举项作为默认值。
- [必须] `enum` 在 C ABI 边界上的兼容资格、按值表示与传递规则统一遵循 [Feng 语言 ABI 互操作规范](./feng-interop.md) 中 `int` 标量规则。
- [禁止] 空 `enum`。
- [禁止] 在同一个 `enum` 中混用显式赋值与隐式取值。
- [禁止] 为枚举项赋非整数字面量值。
- [禁止] 在 `enum` 中声明字段、方法、构造函数、终结器、父类型或泛型参数。
- [禁止] 不同 `enum` 类型之间直接赋值、比较或转换。
- [禁止] `enum` 与 `int` 之间发生隐式转换。
- [禁止] 从 `int` 显式转换到 `enum`。

## 5 编译期

- 编译器必须为每个 `enum` 建立独立的具名类型。
- 编译器必须检查 `enum` 是否位于模块级顶层，并拒绝嵌套声明。
- 编译器必须检查 `enum` 至少包含一个枚举项，并拒绝重复名称。
- 编译器必须检查 `enum` 是否混用了显式赋值与隐式取值；若混用则报错。
- 编译器必须检查显式赋值是否为整数字面量；对全隐式 `enum` 则按声明顺序分配底层 `int` 值。
- 编译器必须检查同一 `enum` 内是否出现重复底层值，若出现则报错。
- 编译器必须按强类型规则检查 `enum` 与 `int` 之间的转换、`enum` 之间的赋值与比较合法性。
- 编译器必须拒绝任何形式的 `int -> enum` 显式转换，不因整数字面量或常量表达式而放宽。
- 编译器必须拒绝 `enum` 上的字段、方法、构造函数、终结器、继承与泛型语法。
- 编译器与 codegen 必须把 `enum` 降为 Feng `int` 对应的稳定标量表示，不得把其 ABI 或宽度语义委托给 C 原生 `enum` 实现细节。
- 编译器必须按 [Feng 语言 ABI 互操作规范](./feng-interop.md) 校验 `enum` 在 ABI 参数、ABI 返回值与 `@abi type` 字段位置的合法性，并按 `int` 标量规则处理其 ABI 表示。

## 6 运行时

- `enum` 值在运行时按其底层 `int` 值表示。
- `enum` 默认值不依赖底层值是否为 `0`；始终取声明顺序中的第一个枚举项。
- 运行时不为 `enum` 引入独立对象头、标签、反射表或专用 helper；对 plain `int` 路径不增加额外运行时开销。
- 当前阶段运行时不提供从任意 `int` 到 `enum` 的动态校验或恢复机制。
