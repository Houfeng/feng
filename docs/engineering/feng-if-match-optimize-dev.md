# if-match 优化：匹配与绑定分离

## 1 问题背景

当前 `if expr { ... }` 条件匹配语法同时承担了两层语义：

1. **匹配判别**：判断目标表达式的运行时值/类型是否命中某个分支标签。
2. **类型收窄 + 变量绑定**：对匹配目标进行类型收窄，并在分支作用域内以收窄后的类型重新绑定同名变量。

当目标表达式是一个简单标识符（如 `v`）时，收窄和绑定可以自然工作：

```feng
if v {
    UserType {
        // v 收窄为 UserType，可以直接使用
    }
}
```

但当目标表达式是 `type.member`、`self.member` 或其他非标识符表达式时，收窄面临根本性困难：

- **静态语言约束**：成员的类型在声明时已确定，不能在分支内把 `self.field` 的类型"收窄"为一个更具体的类型。
- **表达式收窄的局限**：当前实现对非标识符目标采用"表达式结构匹配"收窄（`ExprNarrowingEntry`），仅在收窄为单一 member 时生效，且依赖表达式的结构一致性，脆弱且不通用。
- **多 member 分支无法收窄**：非标识符目标在匹配多个 member 的分支中完全没有收窄能力。

因此需要将**匹配判别**与**匹配并绑定**分离成两种不同的语法形式。

## 2 适用范围

本次优化**仅针对类型匹配**（即目标表达式静态类型为 union-form `spec` 的 union member 匹配）。

值匹配（整型、`string`、`bool` 常量相等性匹配）和区间匹配（`m...n`）保持现有行为不变，不在本次优化范围内。

## 3 设计方案

### 3.1 只匹配不绑定

分支标签仅用于匹配判别，不引入新的局部变量。分支体内通过原始表达式访问目标值，类型保持原始静态类型（不自动收窄）。

```feng
if expr {
    Success { println("ok"); }
    Failure { println("fail"); }
    else { println("other"); }
}
```

适用场景：

- 仅需判断类型，无需在分支内以收窄后的类型使用目标值。
- 目标表达式是非标识符（如 `self.field`、`obj.member`），不希望或无法收窄。

### 3.2 匹配并绑定

分支标签前增加 `name:` 前缀，将匹配到的目标值以收窄后的类型绑定到一个新的局部变量。

```feng
if expr {
    v: Success { println("ok: {0}", v.value); }
    e: Failure { println("fail: {0}", e.message); }
    else { println("other"); }
}
```

适用场景：

- 需要在分支内以收窄后的类型使用目标值。
- 目标表达式是非标识符，但需要一个类型收窄后的局部变量。

### 3.3 绑定变量的可变性

绑定变量默认为 `let`（不可变），也可显式使用 `let` 或 `var` 标注：

```feng
if expr {
    v: Success { v.value = 10; }       // 编译错误，v 默认 let，不可变
    var e: Failure { e.message = "x"; } // var，e 可变
    let r: Success { println("ok"); }   // 显式 let
}
```

### 3.4 同一分支匹配多个 member

当单个分支匹配多个 member 时，绑定变量的类型为收窄后的子集 union 类型，不能直接作为具体类型使用，需要进一步收窄到唯一类型后才可访问：

```feng
if expr {
    v: Named, string {
        // v 的类型为 Named | string（子集 union），不能直接访问
        // 需要进一步收窄到唯一类型后才可使用
    }
}
```

### 3.5 `else` 分支

`else` 分支始终不绑定，不引入局部变量。

### 3.6 混合使用

同一个类型匹配体内，允许部分分支有绑定、部分分支无绑定：

```feng
if expr {
    v: Success { println("ok: {0}", v.value); }
    Failure { println("fail"); }
    else { println("other"); }
}
```

### 3.7 if-match 语句与 if-match 表达式

if-match 作为语句和作为表达式时，匹配与绑定的行为一致，规则不变。各分支返回值类型一致性和 `else` 必选的规则与现有 `if` 表达式规范相同。

```feng
// 表达式形式
let msg = if self.result {
    v: Success { "ok: " + v.value; }
    e: Failure { "fail: " + e.message; }
    else { "unknown"; }
};
```

## 4 两种形式的对比

| 特性            | 只匹配不绑定               | 匹配并绑定                         |
| --------------- | -------------------------- | ---------------------------------- |
| 分支标签语法    | `Type { ... }`             | `name: Type { ... }`               |
| 引入局部变量    | 否                         | 是（分支作用域内）                 |
| 目标值类型      | 保持原始类型               | 收窄为标签类型                     |
| 适用目标表达式  | 任意表达式                 | 任意表达式                         |
| 绑定可见范围    | —                          | 仅当前分支体                       |
| 绑定可变性      | —                          | 默认 `let`，可显式 `let` 或 `var`  |
| `else` 分支     | 无绑定                     | 无绑定                             |
