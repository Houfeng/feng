# Feng 工程文档

本目录保存 Feng 编译器、运行时、工具链、标准库和官网的工程文档，用于记录实现设计、实施步骤、问题分析、优化方案及交付结果。

## 内容边界

本目录包含：

- 面向实现的技术设计与模块划分。
- 开发计划、任务拆分和阶段记录。
- 缺陷分析、修复方案和优化方案。
- 已交付能力的实现记录。
- 构建、发布、安装及官网内容逻辑等工程方案。

本目录不负责定义语言、工具链或运行时的权威行为。需要新增或修改对外行为时，应先更新 [语言与工具规范](../specifications/README.md)，工程文档只引用规范并说明如何实现。

## 文档状态

工程文档可以处于草案、待处理、开发中、已交付或已否决等状态。状态应通过文件名或正文明确表达；历史文档即使保留，也不得覆盖当前规范和当前实现。

面向 Feng 使用者的教程和操作说明归入 [使用手册](../manual/README.md)，尚未形成结论的讨论材料归入 [临时记录](../../notes/README.md)。
