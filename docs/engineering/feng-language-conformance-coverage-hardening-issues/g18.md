## ISSUE-G18-001：非法显式转换仍产生未进入现行 AE 分段规范的旧 `AE0051`

### 归属

- 发现组：G18；
- 关联组：G19～G25 中涉及显式转换的既有或后续映射；
- 发现用例：TYPE04、TYPE04-A。

### 现象与结论

- 最小复现：`let value: i32 = 1; let invalid = (bool)value;`；
- 实际结果：Semantic 在 `validate_cast_expr` 的通用非法转换出口产生 `AE0051`；该码仍出现在旧总表，
  但没有进入当前 `feng-error-codes-ae.md` 的稳定分段；
- 规范依据与预期结果：显式转换资格由表达式主规范统一定义；不同来源 / 目标组合共享同一个通用非法
  转换出口，应使用 AE 表达式段中的同一稳定诊断，不应按普通类型、spec、tuple 或泛型增加特判；
- 结论及根因：早期错误码结构化未迁移显式转换产生点，属于诊断契约未收敛，不改变任何转换的接受、
  拒绝或运行语义。

### 决策与实施

- 状态：待 Review；
- 分类：诊断契约缺口；
- 建议方案：在 AE 表达式段新增 `AE1023`“显式转换资格约束”，将 `validate_cast_expr` 的唯一
  `AE0051` 产生点整体迁移为 `AE1023`；不得只为 G18 普通类型增加分支；
- 是否涉及既有测试修改：是。当前精确断言 `AE0051` 的范围仅有四个 Semantic 测试函数共 11 条：
  `test_object_spec_method_values_reject_invalid_sources`、
  `test_explicit_generic_callable_values_reject_invalid_sources`、
  `test_callable_variadic_shape_mismatches_are_rejected` 和
  `test_object_spec_upcast_rejects_out_of_scope_conversions`；需人工明确批准后才可修改；
- 是否涉及运行时性能：否，只改变编译期错误码；
- 是否涉及 runtime 私有 ABI、公开 ABI 或 `.ft` 格式：否；
- 人工决策与批准范围：待 Review；
- 实际变更：—。

## ISSUE-G18-002：普通对象默认零值循环仍使用旧 Codegen 码且错误复用 ARC 潜在循环图

### 归属

- 发现组：G18；
- 关联组：TYPE08～TYPE09；
- 发现用例：TYPE08、TYPE08-A、TYPE08-B。

### 现象与结论

- 最小复现一：`type Node { var next: Node; } func run() { let node: Node; }`；
- 实际结果一：Semantic 允许声明递归普通对象类型；实际要求默认值时，Codegen 的通用默认值生成路径
  以旧 `CE0226` 拒绝。现行 CE 分段规范已经把该诊断预留为 `CE0911` 并明确继续归属 Codegen；
- 最小复现二：`type Node { var children: Node[]; } func run() { let node: Node; }`；
- 实际结果二：Codegen 的默认零值资格判断首先读取 `feng_semantic_type_is_potentially_cyclic`。该 ARC
  潜在循环图会穿透数组元素类型，因此数组字段形成回边时也会被判为默认零值不安全；
- 规范依据与预期结果：类型规范要求普通对象默认值递归初始化对象字段；内建类型规范同时规定数组
  默认值是长度为零的有效空数组。因此默认零值展开在数组字段处终止，不会为了空数组继续构造元素
  对象。ARC 潜在循环分析需要穿透数组以覆盖对象日后写入数组形成的运行时环，但该图不能直接决定
  初始默认值能否有限生成；
- 结论及根因：默认零值资格与运行时 ARC 潜在循环是两个不同问题，当前 Codegen 复用同一循环标记
  导致数组中断边界过度拒绝；同时该用户可达诊断仍使用已规划迁移的旧 CE 码。

### 决策与实施

- 状态：待 Review；
- 分类：产品缺陷、诊断契约缺口和测试缺口；
- 建议方案：保持现行 CE 规范确定的 Codegen 阶段，不新增 AE 码；把 `CE0226` 迁移为 `CE0911`，并
  使用专门的默认零值依赖判断：仅沿实际需要递归构造默认值的普通对象字段继续，遇到数组、`string`、
  标量、指针及其他已有终止默认值的类别即停止。不得削弱供 ARC 使用的潜在循环图；
- 是否涉及既有测试修改：静态审计未发现既有测试精确断言 `CE0226`；优先新增 G18 Codegen 与 FCTS
  用例。若实施时发现必须修改既有测试，先暂停并取得人工决策；
- 是否涉及运行时性能：不得增加既有合法程序的运行时判断、分支、调用、分配或 ARC。修复仅改变
  编译期资格判断；此前被错误拒绝的数组中断程序按既有数组默认值规则生成空数组，不属于给既有合法
  程序增加开销；
- 是否涉及 runtime 私有 ABI、公开 ABI 或 `.ft` 格式：否；
- 人工决策与批准范围：待 Review；
- 实际变更：—。
