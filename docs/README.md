# Feng 文档

本目录保存 Feng 项目的长期文档，并按文档职责分为以下三类：

- [语言与工具规范](./specifications/README.md)：定义 Feng 的语法、语义、可观察运行时行为、工具接口及其他权威规则。
- [工程文档](./engineering/README.md)：记录实现设计、实施计划、问题分析、优化方案和交付结果。
- [使用手册](./manual/README.md)：面向 Feng 开发者说明如何安装、学习和使用 Feng。

临时记录、讨论材料和尚未归类的内容位于仓库根目录的 [notes](../notes/README.md)，不属于正式文档。

## 文档职责

- 规范回答“Feng 必须具有什么行为”。
- 工程文档回答“仓库如何实现、验证或演进这些行为”。
- 使用手册回答“开发者如何正确使用 Feng 完成工作”。

三类文档不得互相替代。涉及语言、工具链或可观察运行时行为的规则，只在对应规范文档中定义；工程文档和使用手册应引用规范，不重复建立另一套规则。

## 变更顺序

涉及行为变化时，先更新规范，再更新实现，最后更新测试和使用手册。仅涉及实现细节、开发计划或问题修复时，内容归入工程文档；尚未形成结论的讨论内容归入 `notes/`。
