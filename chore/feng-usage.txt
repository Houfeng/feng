Usage:
  feng <command>  [<options>]
  feng <files...> [<options>]

Project:
  feng init       [<name>] [--target=<bin|lib>]
  feng build      [<path>] [--release] [--keep-ir]
  feng check      [<path>] [--format=<text|json>]
  feng run        [<path>] [--release] [--keep-ir]
                  [-- <program-args>...]
  feng clean      [<path>]
  feng pack       [<path>]
  feng deps       <add|remove|install> ...

Compile:
  feng <files...> [--target=<bin|lib>]
                  [--out=<dir>]
                  [--name=<artifact>]
                  [--release]
                  [--keep-ir]
                  [--pkg=<fb-path>...]
                  [--lib=<lib-path>...]

Global:
  -h, --help      Display this message.
  -v, --version   Display version information.

Protocol:
  feng lsp        [--stdio]
  feng dap        [--stdio]
