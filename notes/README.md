# 临时记录

本目录保存讨论性、探索性、短期性或暂未归类的材料。这里的内容可以不完整，也可能随讨论推进而失效，不构成 Feng 的语言规范、工程方案或使用手册。

## 使用原则

- 尚未形成结论的想法、讨论草稿和临时清单可以放在此处。
- 形成稳定规则后，将内容整理到 `docs/specifications/`，并删除或缩减原记录。
- 形成可执行工程方案后，将内容整理到 `docs/engineering/`。
- 形成面向用户的稳定说明后，将内容整理到 `docs/manual/`。
- 已失效且没有保留价值的记录应及时删除，避免被误当作当前结论。
